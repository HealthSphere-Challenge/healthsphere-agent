# MedQuAD Dataset — HealthSphere

## Overview

This directory contains the **MedQuAD (Medical Question Answering Dataset)** used by the HealthSphere AI Agent.

MedQuAD is a medical question-answering dataset containing **47,457 medical question-answer pairs** collected from multiple trusted medical and NIH-related information sources.

In HealthSphere, MedQuAD is primarily used as a **medical knowledge source for the Retrieval-Augmented Generation (RAG) pipeline**.

MedQuAD is **not used to train the HealthSphere predictive Machine Learning model**.

---

## Purpose in HealthSphere

The HealthSphere AI Agent must be able to retrieve relevant medical information before generating an answer.

MedQuAD provides part of this medical knowledge base.

Conceptually:

```text
User Question
      ↓
HealthSphere AI Agent
      ↓
RAG Retriever
      ↓
MedQuAD Knowledge Base
      ↓
Relevant Medical Information
      ↓
LLM
      ↓
Personalized Explanation
```

For example:

```text
User:
"What does high cholesterol mean?"

        ↓

RAG searches MedQuAD

        ↓

Relevant medical information is retrieved

        ↓

The information is provided to the LLM

        ↓

The LLM generates a clear explanation
```

This approach allows the LLM to use retrieved medical information instead of relying only on its internal knowledge.

## Dataset Content

MedQuAD contains **47,457 medical question-answer pairs**.

The dataset covers multiple types of medical questions, including topics such as:

- Diseases
- Symptoms
- Diagnosis
- Treatment
- Prevention
- Causes
- Complications
- Tests
- Medications
- Side effects
- Genetics
- General health information

The dataset is organized into several collections obtained from different medical information sources.

## Raw Data

The directory:

```text
raw/
```

contains the original MedQuAD files collected for HealthSphere.

The raw dataset should remain unchanged.

Files inside `raw/` must not be manually cleaned or modified.

Any transformation must produce new files under:

```text
processed/
```

This allows HealthSphere to preserve the original dataset and maintain a reproducible data-processing pipeline.

---

## Processed Data

The directory:


## RAG Pipeline

MedQuAD will primarily be used through **Retrieval-Augmented Generation (RAG)**.

The planned architecture is:

```text
MedQuAD
    ↓
Preprocessing
    ↓
Clean Medical Documents
    ↓
Chunking
    ↓
Embedding Model
    ↓
Vector Embeddings
    ↓
Vector Database
    ↓
Retriever
    ↓
Relevant Medical Context
    ↓
LLM
```

---

## Embeddings

The processed medical information will be transformed into numerical vectors using an embedding model.

Conceptually:

```text
Medical Text

"What are the symptoms of diabetes?"

            ↓

      Embedding Model

            ↓

[0.21, -0.43, 0.76, ...]
```

Embeddings allow HealthSphere to perform **semantic search**.

This means that the system can retrieve medically relevant information even when the user's wording is different from the wording used in MedQuAD.

---

## Vector Database

The generated embeddings will later be stored in a vector database.

Conceptually:

```text
MedQuAD
   ↓
Chunks
   ↓
Embeddings
   ↓
Vector Database
```

When the user asks a question:

```text
User Question
      ↓
Embedding
      ↓
Vector Search
      ↓
Most Relevant MedQuAD Chunks
      ↓
LLM Context
```

The exact vector database technology will be selected during implementation.

---

## Role of the LLM

MedQuAD does not directly generate the final answer.

The responsibilities are separated:

```text
MedQuAD
   ↓
Provides medical knowledge

RAG
   ↓
Retrieves relevant information

LLM
   ↓
Generates the natural-language response

AI Agent
   ↓
Orchestrates the complete process
```

This separation allows HealthSphere to maintain a modular AI architecture.

## MedQuAD vs MTS-Dialog

HealthSphere uses MedQuAD and MTS-Dialog for different purposes.

### MedQuAD

Main purpose:

```text
Medical Knowledge
      ↓
RAG
      ↓
Knowledge Retrieval
```

Used for:

- Medical information
- Medical Q&A
- RAG knowledge base
- Context retrieval

### MTS-Dialog

Main purpose:

```text
Doctor–Patient Conversations
          ↓
Conversation Analysis
          ↓
Agent Behavior
```

Used for:

- Conversation patterns
- Follow-up question strategies
- Prompt design
- Conversational evaluation

Therefore:

```text
MedQuAD
   → What medical information can be retrieved?

MTS-Dialog
   → How should the conversation be structured?
```

## MedQuAD vs Predictive Machine Learning

MedQuAD is not used to train the HealthSphere predictive ML model.

HealthSphere separates these components.

### Predictive AI

Repository:

```text
healthsphere-ai
```

Pipeline:

```text
Structured Patient Data
        ↓
Preprocessing
        ↓
Machine Learning Model
        ↓
Risk Assessment
```

Synthea is used as the initial structured synthetic healthcare dataset for this component.

### AI Agent

Repository:

```text
healthsphere-agent
```

Pipeline:

```text
User Question
      ↓
AI Agent
      ↓
RAG
      ↓
MedQuAD
      ↓
LLM
      ↓
Response
```

Therefore:

```text
Synthea   → Structured health data / ML experimentation

MedQuAD   → Medical knowledge / RAG

MTS-Dialog → Conversation design and evaluation
```
